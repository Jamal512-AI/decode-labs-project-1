White-Box AI Chatbot: The DecodeLabs Logic Engine
Tired of AI hallucinations? This project is a shift away from "Black-Box" unpredictability toward a transparent, White-Box AI solution. Built as a foundational project during an AI Internship, this chatbot prioritizes deterministic logic, predictability, and 100% traceability.

🚀 Key Features
1. The IPO Pipeline
The system operates on a strict Input → Process → Output architecture. Every user query is sanitized and normalized before being matched against the logic engine with mathematical precision.

2. O(1) Intent Matching
Engineered for high performance, the engine uses optimized key-hit logic to deliver responses with near-zero latency, ensuring a seamless user experience.

3. Real-Time Traceability
Featuring a Live Trace Bar, the system provides a peek under the hood. Users can see the exact path the logic took—from initial sanitization to the final rule hit.

4. Safety Guardrails
Integrated AI guardrails ensure the engine stays strictly within its defined knowledge base, making it an ideal choice for high-stakes, domain-specific applications where accuracy is non-negotiable.

🛠️ Tech Stack
Logic Engine: High-performance Vanilla JavaScript.

Frontend: HTML5 & Advanced CSS featuring a "Cyberpunk" inspired UI with Glassmorphism effects.

Architecture: State-machine based session management with a graceful "Kill Command" shutdown.

Live Link: https://rule-based-chatbot-flax.vercel.app/

📖 What I Learned
Building this engine from scratch reinforced the importance of deterministic logic in AI development. It proved that in many professional applications, knowing why a system gave an answer is just as important as the answer itself.
